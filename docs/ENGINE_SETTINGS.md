# Engine operation

The single project setting table is [PROJECT_SETTINGS](PROJECT_SETTINGS.md). Resolution is **explicit flags > environment > project configuration > engine preferences**, with operational defaults only where the driver needs them. Unspecified model and effort are omitted from engine arguments; native login, MCP and user preferences remain available. Engines receive only compatible tool formats; the catalog and receipt name adaptations and unsupported fields.

Claude uses `CLAUDE_MODEL`, `CLAUDE_EFFORT`, `CLAUDE_HEADLESS_PERMISSION_MODE` and `CLAUDE_STRICT_MCP`. Headless permission mode defaults to `bypassPermissions`; strict MCP defaults off. Existing native hooks are preserved when compatible; a foreign Stop or PreToolUse driver is a collision. [Claude setup](../CLAUDE_CODE_SETUP.md) explains the driver.

Codex uses `CODEX_MODEL`, `CODEX_REASONING_EFFORT`, `CODEX_SANDBOX`, `CODEX_HOME_MODE`, `FRAMEWORK_CODEX_HOME`, `CODEX_INSTRUCTIONS_MAX_BYTES` and `CODEX_STRICT_VERSION`. Personal home and `danger-full-access` are defaults. Managed execution home and sandboxing are explicit choices. Authentication is never copied. To log into a managed home, scope `CODEX_HOME` to login only, restore its previous value, then select that home with `FRAMEWORK_CODEX_HOME`. A positive explicit instruction limit is honored; otherwise the engine decides. Formats were checked with Codex 0.162; strict version checking is opt-in. Unrecognized versions are reported rather than silently claimed compatible.

OpenCode uses `OPENCODE_MODEL` and `OPENCODE_VARIANT`. Its project guard lives in `.opencode/plugins/0-code-safety-guard.js`, calling the shared installed detector. Native personal MCP and account connectors are not transferred into another engine merely because their names match. A connector unavailable in an engine is reported.

Shared driver variables are `AGENT_IDLE_TIMEOUT_MS`, `AGENT_TURN_TIMEOUT_MS`, `AGENT_NETWORK_RETRIES`. Defaults are 99 minutes idle, 9999 hours per turn and retries without a framework cap. Zero disables a timeout. These are operational timeouts, separate from iteration or budget limits in state.

`SAFETY_GUARD_MODE` overrides project guard mode. `arbiter` permits safe tools and denies dangerous ones; `guard-only` denies dangerous tools and otherwise leaves native decisions alone; `confirm` requires an explicit substantive reason for a contextual exception; `allow-all` disables denials. Force push requires a reason in every enabled mode. Root/home destruction, formatting and mass process termination cannot be confirmed. Invalid mode names retain the safe default and report the error. Native `ask` rules can still prompt regardless of the hook; inspect their origin before changing them.

Doctor checks the local CLI with `--version`, owned files, state, local MCP prerequisites and installed guard denial/allow controls. It invokes no model. Successful registration is distinct from a live MCP connection or external authorization. The public catalog contains context7, playwright, chrome-devtools, sequential-thinking and memory; private tool bodies are excluded. npm versions in the manifest are tested SemVer minima, and valid newer packages are preserved after separate name/entry checks. Package requirements and native user-directory overrides are listed in the settings guide.

When `session_logs` is enabled, the external supervisor records each attempt for Claude, Codex and OpenCode under the configured logs role, including probes, failures and retries. Known secrets are redacted before serialization; arbitrary private text can remain. The journals are not a second source of token accounting. Claude hooks also capture native session transcripts and summaries. Keep logs out of version control; disable dependent `token_usage` when disabling `session_logs`.

In an installed project's personal Codex mode, captured guard snapshots stay in ignored .0-code/run/codex-guard; CODEX_HOME still points to the personal login. The host restores its captured bytes before turns. Explicit managed authentication homes remain separate and cannot overlap personal homes or writable roots. CLI MCP overrides use literal dotted keys; TOML table quoting is a different syntax.
