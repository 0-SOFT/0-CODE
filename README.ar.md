# 0-CODE

**الإصدار:** v2.0.2

دورة تطوير ذاتية لـ **Claude Code وCodex وOpenCode** تُدمج في مشروع قائم. يمكن لتوجيه دورة واحد أن يجمع البحث والتنفيذ والإصلاحات والتدقيق وإصدار النسخ.

## الدمج بواسطة وكيلك

اطلب في جلسة وكيل المشروع: **«ادمج 0-CODE من https://github.com/0-SOFT/0-CODE واتبع ملف `INTEGRATE.md` فيه».** استخدم نسخة من المصدر العام خارج المشروع المستهدف، ويمكن اختيار وسم إصدار محدد. يخدم [القالب القصير نفسه](INTEGRATE.md) التحديث والإزالة في المحركات الثلاثة.

يجرد الوكيل الوثائق والأدوات وMCP وأوامر الفحص، ويحل الخيارات الملتبسة فعلًا، ويعرض الخطة ثم يثبت ويشغل doctor ويلتزم بالتغييرات في فرع منفصل. أدوات المشروع لها الأولوية. [البدء اليدوي](QUICKSTART.md).

## ما الذي يُثبَّت

توجد شيفرة الإطار والإعدادات والمخططات والوحدات والقوالب في **`.0-code/`**. تتلقى المحركات فقط الخطافات والتعليمات والأدوات المتوافقة في مواضعها الأصلية وإضافة الحماية لـ OpenCode. تُحفظ الشيفرة والوثائق القائمة؛ تُكتشف التعارضات والملفات المملوكة المعدلة قبل الكتابة. ملفات التشغيل والنسخ الاحتياطية في `.0-code/run/` المستثنى من git.

[PROJECT_SETTINGS](docs/PROJECT_SETTINGS.md) هو مرجع الإعدادات الوحيد. يمكنك قبول الوثائق الافتراضية أو تغيير أدوار معينة أو ربط جميع الأدوار بتقاليد المشروع القائمة. تظل الحالة وثيقة قابلة للقراءة آليًا. تستخدم الوثائق البشرية اللغة المحددة، وتبقى تعليمات الوكيل بالإنجليزية.

النموذج وجهد الاستدلال وتسجيل الدخول تحت سيطرة المالك. أولوية الإعدادات هي **الخيارات الصريحة > البيئة > إعدادات المشروع > تفضيلات المحرك الأصلية**. يرث النموذج والجهد غير المحددين الإعدادات القائمة؛ لا تُنسخ بيانات المصادقة أبدًا. انظر [إعدادات المحركات](docs/ENGINE_SETTINGS.md).

يحتوي [الفهرس العام](toolset/CATALOG.md) على **خمسة خوادم MCP افتراضية: context7 وplaywright وchrome-devtools وsequential-thinking وmemory**. تحتاج حزم npm بإصدار يساوي الحد الأدنى المختبر وفق SemVer أو يزيد عليه، مع اسم الحزمة ونقطة الدخول الصحيحين؛ احتفظ بالإصدارات الأحدث الصالحة. لا تحتاج مفتاح API خارجيًا؛ وتحتاج أدوات المتصفح أيضًا متصفحًا متاحًا. التسجيل ونجاح doctor لا يثبتان اتصالًا فعليًا. تُستثنى ملفات التنفيذ الخاصة للمهارات والوكلاء والأوامر والقواعد. تبقى أمثلة خدمات الحسابات الاختيارية في بيان MCP معطلة حتى إعدادها والتصريح لها صراحة.

الافتراضي هو **تثبيت مستقل واحد لكل مستخدم** تشترك فيه مشاريعه. لا يغير تكرار الاختيار نفسه شيئًا. يثبت نطاق project اختيارًا مختلفًا لمشروع معين. إزالة المشروع تبقي أدوات الجهاز؛ يزيلها `uninstall-tools` منفصلًا ويعيد إعداداتها الأصلية السابقة. لا تُنسخ بيانات المصادقة أبدًا. [الإعدادات والمتطلبات](docs/PROJECT_SETTINGS.md).

## العمل والصيانة

من المشروع المثبت:

```bash
node .0-code/tools/0code.mjs doctor --json
node .0-code/tools/0code.mjs start <cycle-prompt> --max 60
node /path/to/new-source/tools/0code.mjs upgrade --project . --dry-run
node .0-code/tools/0code.mjs uninstall --dry-run
```

املأ القالب الوحيد `.0-code/templates/cycle.md`. يكتب `start` الحالة ذريًا ويعرض أمر المشغل. أعد تشغيل Claude لتحميل الخطافات؛ يستخدم Codex وOpenCode المشرف الخارجي. لكل مجلد دورة نشطة واحدة. حدود التكرار والإنفاق اختيارية؛ حد المال يحتاج بيانات تكلفة المشرف. سجل الأعمال الطويلة في الحالة بدل الانتظار في حلقات sleep.

يدعم المصدر العام التثبيت الجديد وتحديث بنية `.0-code/`. **لا يتوفر الترحيل التلقائي لتثبيتات 1.x القديمة في جذر المشروع دون `config/legacy-installations.json`، وهو مستثنى من الشجرة العامة.** استخدم `migrate --dry-run` ثم `migrate` فقط مع مصدر يحتوي أدلة الملكية من الإصدارات المنشورة. لا تُزال إلا الملفات المثبت انتماؤها للإطار بايتًا ببايت والكتل المملوكة المطابقة تمامًا؛ تبقى الوثائق وتُنقل بيانات التشغيل أو تُؤرشف مع نسخ احتياطية. أنهِ أي دورة قديمة نشطة أولًا؛ وعند غياب الأدلة احتفظ بالملفات القديمة وراجع ملكيتها قبل تعديلها.

تشرح [إعدادات المحركات](docs/ENGINE_SETTINGS.md) و[Claude](CLAUDE_CODE_SETUP.md) و[دليل التطوير](GUIDELINE.md) و[الأمان](SECURITY.md) التشغيل والتحقق. في المصدر شغل `node tests/run.mjs --coverage-min=80` و`bash tests/smoke.sh`؛ النتائج المحلية دليل، وتوافر CI مسألة منفصلة.
