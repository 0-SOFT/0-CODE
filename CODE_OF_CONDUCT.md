# Code of conduct

## The short version

Be straightforward and be kind. Disagree with the argument, not the person.

## What is expected

- **Say what you observed.** "This fails on Windows with X" is worth more than "this is broken".
- **Assume competence.** The other person usually had a reason; ask what it was before assuming
  there was none.
- **Accept being wrong gracefully.** This project keeps a public list of its own disproven
  assumptions — see [docs/PROVEN.md](docs/PROVEN.md). Being corrected is a normal outcome here, not
  a loss.
- **Keep criticism about the work.** Code, documents and decisions are fair game. People are not.

## What is not acceptable

Personal attacks, harassment, discriminatory language, deliberate derailing, and publishing
someone's private information.

## Scope

This applies in issues, pull requests, discussions, and any other space where the project is being
worked on.

## Enforcement

Report a problem privately through a
[security advisory](https://github.com/0-SOFT/0-CODE/security/advisories/new) if it involves
sensitive details, or by opening an issue if it does not. Reports are handled confidentially.
Responses range from a request to change behaviour up to a ban, depending on severity and pattern.
