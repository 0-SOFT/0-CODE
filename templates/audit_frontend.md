# Frontend audit

Read the active prompt, project inventory and configuration. Inspect real user journeys, loading/error states, keyboard navigation, accessibility, layout and consistency across supported viewports. Use the project's actual build and test commands.

Write the report, machine ledger and repair prompt in their configured roles and language. Follow the production audit ledger contract. If the repository has no frontend, record an empty ledger with the inspected scope and an explicit explanation of non-applicability; do not silently omit the direction.
