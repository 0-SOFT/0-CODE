# 0-CODE

**Версия:** v2.0.3

Автономный цикл разработки для **Claude Code, Codex и OpenCode**, который встраивается в существующий проект. Один промпт цикла может объединять исследование, реализацию, исправления, аудиты и выпуск.

## Интеграция через агента

В сессии агента своего проекта напишите: **«Интегрируй 0-CODE из https://github.com/0-SOFT/0-CODE; следуй его `INTEGRATE.md`».** Используйте публичную копию исходников вне целевого проекта, при необходимости на выбранном теге выпуска. Один [короткий шаблон](INTEGRATE.md) также ведёт обновление и удаление во всех трёх движках.

Агент собирает опись документов, инструментов, MCP и команд проверок, разрешает только реальные неоднозначности, показывает план, устанавливает, запускает doctor и коммитит в отдельной ветке. Инструменты проекта имеют приоритет. [Ручной запуск](QUICKSTART.md).

## Что устанавливается

Код фреймворка, настройка, схемы, модули и шаблоны живут в **`.0-code/`**. Движки получают необходимые записи хуков, инструкций, совместимых инструментов и плагин стража OpenCode. Код и документы владельца сохраняются; пересечения и изменённые собственные файлы обнаруживаются до записи. Служебные файлы и резервные копии находятся в исключённом из git `.0-code/run/`.

Единственный справочник настройки — [PROJECT_SETTINGS](docs/PROJECT_SETTINGS.md). Можно принять документы по умолчанию, переопределить отдельные роли или связать все роли с принятой схемой проекта. STATE остаётся машинным документом. Человеческие документы пишутся на выбранном языке, инструкции агента — по-английски.

Модель, усилие рассуждения и вход принадлежат владельцу. Приоритет настроек: **явные флаги > окружение > конфигурация проекта > родные предпочтения движка**. Неуказанные модель и усилие наследуются; авторизация никогда не копируется. См. [настройки движков](docs/ENGINE_SETTINGS.md).

[Публичный каталог](toolset/CATALOG.md) содержит **пять штатных MCP: context7, playwright, chrome-devtools, sequential-thinking и memory**. Нужны npm-пакеты не ниже проверенной границы SemVer, с правильным именем и точкой входа; подходящие новые версии сохраняются. Внешний API-ключ не нужен; браузерным инструментам также нужен доступный браузер. Регистрация и успешный doctor не доказывают живое соединение. Приватные тела навыков, агентов, команд и правил исключены. Необязательные примеры учётных сервисов в манифесте MCP остаются выключенными до явной настройки и авторизации.

Умолчание — **одна независимая установка инструментов на пользователя**, общая для его проектов. Повтор того же выбора ничего не меняет. Область project закрепляет другой набор в проекте. Удаление проекта оставляет машинные инструменты; `uninstall-tools` снимает их отдельно и восстанавливает прежние настройки. Auth не копируется. [Настройка и зависимости](docs/PROJECT_SETTINGS.md).

## Работа и обслуживание

Из установленного проекта:

```bash
node .0-code/tools/0code.mjs doctor --json
node .0-code/tools/0code.mjs start <cycle-prompt> --max 60
node /path/to/new-source/tools/0code.mjs upgrade --project . --dry-run
node .0-code/tools/0code.mjs uninstall --dry-run
```

Заполните единственный `.0-code/templates/cycle.md`. `start` атомарно задаёт состояние и выводит команду водителя. Claude нужно перезапустить для загрузки хуков; Codex и OpenCode используют надзиратель. В одной папке один цикл. Пределы итераций и расходов добровольны; денежный предел требует данных стоимости от надзирателя. Долгую работу регистрируйте в STATE вместо опроса со сном.

Публичная копия поддерживает новую установку и обновление структуры `.0-code/`. **Автоматическая миграция старой 1.x с файлами в корне недоступна без `config/legacy-installations.json`, который исключён из публичного дерева.** Запускайте `migrate --dry-run`, затем `migrate` только из исходников с доказательствами владения из опубликованных выпусков. Снимаются только побайтно доказанные файлы и точные собственные блоки; документы остаются, служебные данные переносятся или архивируются с копиями. Сначала завершите живой старый цикл; без доказательств сохраняйте старые файлы и проверяйте владение до изменений.

[Настройки движков](docs/ENGINE_SETTINGS.md), [установка Claude](CLAUDE_CODE_SETUP.md), [руководство разработки](GUIDELINE.md) и [безопасность](SECURITY.md) описывают работу и проверку. В исходниках: `node tests/run.mjs --coverage-min=80` и `bash tests/smoke.sh`. Локальный результат — доказательство; доступность CI проверяется отдельно.
